# 道路交点与交点间直线生成：流程图与空间计算逻辑图

本文基于《道路交点与交点间直线生成 P0 技术方案》，分别展示批处理闭环和空间计算核心逻辑。图中将“数据异常隔离”“道路级成线资格”“整批版本发布”作为不同层次处理：单条记录异常不应中断全城任务；道路存在影响拓扑或排序的阻塞异常时不发布该道路线段；全量结果完成对账后再切换正式版本。

## 1. 全流程闭环

```mermaid
flowchart TD
    A["开始：创建 run_id，固定城市、参数和规则版本"] --> B["导入道路片段与来源元数据"]
    B --> C{"WKT、SRID、几何类型、组合键及排序契约是否通过校验？"}
    C -- "否" --> C1["写入输入异常表；标记相关道路输入不完整"]
    C -- "是" --> D["标准化道路名称与类型；识别高架、高速排除记录"]
    C1 --> D
    D --> E{"高架、高速排除依据是否完整？"}
    E -- "否" --> E1["批次预处理失败；修正排除配置后重跑"]
    E -- "是" --> F["建立 road_family_id 与 route_id；过滤排除片段"]
    F --> G["建立 GiST 索引并 ANALYZE"]
    G --> H["按 fragment_id 分批，对全城有效片段做原始几何求交"]
    H --> I["提取点状交集；重合线与混合交集写入异常记录"]
    I --> J["追加检测非简单 LineString 的片段内部自交"]
    J --> K["按坐标精度归并候选点，保留全部来源关系"]
    K --> L["逐节点构造局部线网并计算分支度数"]
    L --> M{"节点分类及局部拓扑是否明确？"}
    M -- "否" --> M1["记录拓扑阻塞异常；相关道路 edge_ready=false"]
    M -- "是" --> N["保留路口接触点；排除同一道路系列的纯连续点"]
    M1 --> O["按 route_id 和 osm_id 建立片段顺序"]
    N --> O
    O --> P["用相邻端点代价定向片段；定位并排序交点事件"]
    P --> Q{"方向、链顺序、重复事件及闭环状态是否可判定？"}
    Q -- "否" --> Q1["记录排序阻塞异常；相关道路不发布线段"]
    Q -- "是" --> R["对每条可成线道路按相邻事件两点生成直线"]
    Q1 --> S["汇总成功道路、正常无边道路与阻塞异常道路"]
    R --> S
    S --> T["校验几何、端点、相邻事件、计数、追溯关系和重复运行幂等性"]
    T --> U{"全量结果是否满足发布约束？"}
    U -- "否" --> U1["保留上一正式版本；记录失败项，修复后以新 run_id 重跑"]
    U1 --> B
    U -- "是" --> V["事务切换当前结果版本；保存运行参数、统计和输入摘要"]
    V --> W["完成：交点表、道路事件表、线段表及异常/运行报告可追溯"]
```

### 闭环说明

- 输入级阻断（例如无法确认高架过滤依据）会停止该批次，修复配置后重新运行。
- 可隔离的数据问题进入异常表；不受影响的道路仍可继续处理。
- 纯连续点不作为交点事件。重叠、节点拓扑不确定或定向歧义会阻止受影响道路发布线段。
- 道路只有零个或一个有效交点属于正常无边结果，不等同任务失败。
- 发布前核验结果计数和几何约束；失败时保留上一版，成功后通过事务切换版本指针，避免暴露半成品。
- 新生成的直线不参与本批次求交；下一次运行也必须使用原始输入片段作为交点来源。

## 2. 空间计算逻辑图

```mermaid
flowchart TD
    subgraph INPUT["输入与片段关系"]
        A["WGS84 原始 LineString 片段"] --> B["过滤高速、高架；绑定 city、road_name、type"]
        B --> C["road_family_id：识别同一道路系列"]
        C --> D["route_id：可选区县与 chain_id 的成线分组"]
        D --> E["route_id 内按数值 osm_id 排序"]
    end

    subgraph DISCOVERY["原始几何交点发现"]
        E --> F["GiST 候选筛选：包围盒相交"]
        F --> G["ST_Intersects 精确判断"]
        G --> H["ST_Intersection 求交并展开所有几何成员"]
        H --> I{"交集成员类型？"}
        I -- "Point / MultiPoint / GeometryCollection 中的点" --> J["候选交点；记录片段对来源"]
        I -- "LineString 重合部分" --> K["记录 OVERLAP；关联道路禁止自动成线"]
        I -- "空或其他" --> L["不生成点候选；按异常规则记录"]
        E --> X["非简单片段：拆基本段，检测片段内部自交"]
        X --> J
    end

    subgraph CLASSIFY["候选点归并与纯切割点判定"]
        J --> M["按极小数值容差归并；保留所有来源片段"]
        M --> N["对节点关联片段构造局部线网并节点化"]
        N --> O["计算独立线分支 degree；复核点在线上"]
        O --> P{"分类规则"}
        P -- "degree ≥ 3 且拓扑明确" --> Q["JUNCTION：保留"]
        P -- "degree = 2，存在不同 road_family_id" --> R["ROAD_CONTACT：保留"]
        P -- "degree = 2，同一 road_family_id 且无异常" --> S["CONTINUATION：纯连续点，排除"]
        P -- "degree ≤ 1、重叠或拓扑不确定" --> T["UNRESOLVED / OVERLAP：记录异常并阻止相关道路成线"]
    end

    subgraph ORDER["道路内交点事件排序"]
        Q --> U["为关联 route_id 建立经过事件"]
        R --> U
        U --> V["两状态动态规划：原片段方向 / 反向"]
        V --> W{"相邻端点连接关系是否明确？"}
        W -- "连接" --> Y["使用连接约束定向"]
        W -- "存在缺口但可按最小端点距离定向" --> Z["标记 INFERRED_GAP；不补线、不造交点"]
        W -- "近似最优方向影响事件先后" --> AA["ORIENTATION_AMBIGUOUS：阻止该道路成线"]
        Y --> AB["ST_LineLocatePoint；自交或闭合片段按基本段分别定位"]
        Z --> AB
        AB --> AC["按 frag_seq、片段内 fraction 排序为 event_seq"]
        AC --> AD["仅合并同节点、相邻片段首尾相接的重复事件"]
    end

    subgraph BUILD["相邻交点成线"]
        AD --> AE{"道路是否可成线且事件数足够？"}
        AE -- "否：少于两个事件或存在阻塞异常" --> AF["无边结果或道路级异常；保留原因"]
        AE -- "是：开放道路" --> AG["LEAD 取相邻事件；闭环仅在已证明闭合时补末到首"]
        AG --> AH["ST_MakeLine(Point, Point)：输出两端点直线"]
        AH --> AI["计算 geography 米制长度；附 gap、质量和来源追溯字段"]
        AI --> AJ["输出边不再参与交点发现"]
    end
```

### 空间逻辑要点

1. **交点来源**：交点只来自有效原始片段之间的精确交集，以及非简单 LineString 内部自交检测。包围盒只用于缩小候选范围。
2. **纯切割点**：以局部拓扑定义判断。degree 为 2、仅属于同一 road_family_id 且没有拓扑异常时，归为 CONTINUATION 并排除；不能因为点是片段端点就直接删除。
3. **道路归属与排序分开**：road_family_id 用于识别道路系列及判断纯连续点；route_id 用于具体排序、配对和成线，避免把多个独立道路链串起来。
4. **定向和排序**：osm_id 提供片段间顺序，动态规划选择每个片段的坐标方向；片段内按线性位置排序。节点与道路经过事件分开保存，以保留自交、闭环中的多次经过。
5. **缺失片段**：已有交点仍按事件顺序直接连接；缺口只作为质量信息记录，不从连接直线反推新交点。
6. **输出语义**：每条 LineString 只有两个端点，表达交点间直线连接，不代表原道路曲线或实际道路里程。长度用 WGS84 geography 计算为米。

## 3. 图中名称与方案术语对应

| 图中术语 | 含义 |
|---|---|
| road_family_id | 地市＋标准化道路名称＋标准化道路类型，用于识别道路系列 |
| route_id | road_family_id 加可选区县与 chain_id，用于排序和成线 |
| degree | 候选交点处局部线网的独立分支数 |
| CONTINUATION | 同一道路系列的二度连续点，按纯切割连接点排除 |
| JUNCTION / ROAD_CONTACT | 保留的路口或不同道路组接触点 |
| event | 某条 route_id 沿空间顺序经过某个 node 的一次记录 |
| edge | 两个相邻交点事件之间生成的两点直线 |
| INFERRED_GAP | 片段端点不连接时按方案规则推断的定向质量标记 |
