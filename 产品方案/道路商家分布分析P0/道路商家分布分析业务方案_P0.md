# 道路商家分布分析业务方案

版本：V0.2  
日期：2026年10月16日  
依据：业务架构 V0.3、path 拓宽思路，以及本轮确认的交叉圆域名称优先、候选补齐与行政边界道路唯一归属规则。

## 1 方案目标与范围

本方案以道路与商家 POI 的空间关联为业务核心：使用道路 `path`，按道路等级向两侧拓宽形成面状关联范围；通过点面覆盖关系确定商家候选道路；在道路交叉圆域内先用 POI 已有道路名称匹配参与交叉的道路，未匹配时在补齐的空间候选中取最近；普通多面命中与无面兜底通过 POI 到道路 `path` 的最短距离确定唯一归属。

最终形成“每个商家唯一关联一个区县道路单元”的结果，支撑省—市—区县汇总、道路比较及单条道路商家位置分析。

P0 沿用六个功能模块、商家数量、道路商家密度、行业结构和沿路分布四项指标；自定义标签仅预留。本文只细化业务规则，不展开前端、数据库、接口、技术选型或部署。

### 1.1 固定业务边界

- 道路范围直接使用客户提供并按其条件过滤后的全省道路数据。
- 道路空间表达只使用 `path`，不读取或使用道路 `boundaries`。
- 商家使用 POI 经营位置参与计算；仅交叉圆域内优先使用 POI 已有道路名称匹配参与交叉的道路。名称缺失或未匹配直接按空间距离处理，不从 `address` 提取道路名称。
- 道路按区县拆分，商家只在其唯一所属区县内关联道路。
- 交叉点优先处理，执行“参与交叉道路名称匹配优先、未匹配则补齐候选取最近”；其他区域采用“单面直接归属、多面取最近、无面最近兜底”。
- 最小距离兜底结果直接进入正式统计，不增加抽样验证、人工确认、兜底占比或准确率验收门槛。

## 2 输入与分析对象

| 输入或对象 | 最小业务内容 | 用途 |
| --- | --- | --- |
| 道路数据 | 稳定道路身份、名称、path、可用道路等级 | 生成道路关联面、计算距离及道路长度 |
| 商家 POI | 门店标识、经营位置、一二级行业等已有属性；可选的已有道路名称字段 | 确定商家位置、唯一归属及行业统计；道路名称仅用于交叉圆域优先匹配，缺失不阻断计算 |
| 行政区划边界 | 省、市、区县编码、层级关系及边界 | 切分道路，确定商家行政归属及汇总关系 |
| 等级拓宽参数 | 分类体系、等级、单侧拓宽距离 | 控制不同道路的关联范围 |
| 区县道路单元 | 原道路身份与区县编码 | 作为道路统计及分析基本单元，可包含多个片段 |
| 道路计算片段 | 同一区县内等级、拓宽距离一致的一段 path，保留来源身份 | 点面判断、点到线距离及分等级计量 |

道路计算片段用于完成空间计算，不增加新的产品模块或行政分析层级；其结果汇总到区县道路单元。同名道路不能仅凭名称合并，同一道路的来源片段按已有道路身份关联。

### 2.1 计算口径

1. 道路、POI 与行政区划边界使用一致的坐标口径；拓宽、距离和长度均按米计算，不直接把经纬度数值当作米。
2. 点到线距离是 POI 到完整 path 线段的最短距离，包含到线段内部或端点的距离，不是只比较 path 顶点。
3. 行政归属按 POI 位置确定。恰在行政边界上且同时命中多个区县时，按区县编码固定升序选择一个，保持唯一。
4. 重复 POI 按已有门店标识合并，不同经营门店分别计数。商家原始位置保留，不因归属计算移动位置。

## 3 按道路等级将 path 拓宽成面

### 3.1 拓宽距离的定义

将道路计算片段的 path 记为 `L`，对应的单侧拓宽距离记为 `b`。道路关联面定义为：

`B = {位置 x｜x 位于该区县内，且 x 到 L 的最短距离 ≤ b}`

例如，`b = 40 米`表示 path 左右各拓宽 40 米，直线路段的关联带总宽约 80 米。该参数是商家空间关联范围，不等同于道路实际路面宽度，也不代表国家标准规定的道路宽度。

采用两侧等距离拓宽，端点和转弯处按圆形距离范围处理。关联面保留道路身份，允许不同道路的面相互重叠，不通过合并或预先裁分面来强制确定商家归属。

### 3.2 P0 建议初始参数

以下数值为本方案提出的 P0 初始业务参数，供本轮审核；它们不是国家道路宽度标准。距离确定后，同一批分析统一使用一套参数。

| 道路分类体系 | 等级 | 单侧拓宽距离 b |
| --- | --- | --- |
| 城市道路 | 快速路 | 50 米 |
| 城市道路 | 主干路 | 40 米 |
| 城市道路 | 次干路 | 30 米 |
| 城市道路 | 支路 | 20 米 |
| 公路技术等级 | 高速公路 | 50 米 |
| 公路技术等级 | 一级公路 | 40 米 |
| 公路技术等级 | 二级公路 | 30 米 |
| 公路技术等级 | 三级公路 | 20 米 |
| 公路技术等级 | 四级公路 | 10 米 |
| 等级缺失或暂不能映射 | 未知等级 | 20 米 |

每个道路计算片段只取一个拓宽参数：优先使用适用的城市道路等级，其次使用可用的公路技术等级，其余使用未知等级参数。国道、省道等行政分类保留为分类属性，不直接推定技术等级或叠加拓宽距离。

同一道路不同部分等级不同时，按各部分等级分别拓宽，结果仍归入其所属区县道路单元；未知等级使用默认参数完成计算，不阻断 POI 关联。

### 3.3 行政拆分与面范围

先保留客户原始 path 的道路身份及交叉关系，再按区县边界形成计算片段，生成对应拓宽面，并把面限制在本区县范围内。

道路长度只计算唯一归属该区县的 path 长度。普通穿越行政边界的道路按各区县内实际长度拆分；同一来源 path 沿两个或多个区县共享边界延伸时，将重合部分单独形成片段，按相关区县编码固定升序选择一个区县唯一归属。该片段仅在归属区县生成拓宽面、进入关联候选和累计道路长度，其他区县不复制该片段。不同来源道路不因几何重合而合并。

行政边界产生的切分端点只是道路拆分位置，不作为新交叉点。仅接触边界的零长度位置不单独形成道路计算片段或累计长度。

## 4 道路交叉点范围与归属规则

### 4.1 交叉点及圆域

交叉点由不同道路 path 的点状相交位置生成，包括十字交叉、T 形交汇和不同道路端点相接。同一位置有多条道路相交时，作为一个交叉点，保留全部参与道路。

设交叉点为 `q`，参与交叉的道路片段集合为 `S(q)`，各自单侧拓宽距离为 `b(s)`，则：

`交叉点半径 R(q) = max{b(s)｜s 属于 S(q)}`

`交叉点圆域 J(q) = {位置 x｜x 到 q 的距离 ≤ R(q)}`

例如，主干路单侧拓宽 40 米、支路单侧拓宽 20 米，其交叉点圆域半径为 40 米。这里取参与该交点道路的最大单侧拓宽距离，不取双侧总宽，也不取全省所有道路中的最大值。

交叉点识别在行政切分前完成；圆域与某区县相交时，保留其对该区县的影响，参与道路片段仍限定为按第 3.3 节唯一归属该区县的有效片段；共享边界片段不在多个区县重复成为候选。

### 4.2 圆域内名称优先，未匹配则补齐候选取最近

当商家 POI 位于交叉点圆域内或圆周上时：

1. 合并所命中圆域的参与道路片段并去重，按第 3.3 节限定为本区县的有效片段，记为交叉候选集合 `I`。
2. 读取 POI 已有道路名称字段，与 `I` 中道路名称匹配。P0 仅去除名称首尾空白后做非空名称全等比较，不做模糊匹配、简称推断或从 address 提取道路名称。
3. 匹配到一个区县道路单元时，直接归入该单元；在其匹配片段中取最近 path，记录对应片段、等级及沿路位置。匹配到多个单元时，仅在匹配片段中按第 5.3 节最近距离与固定同距规则确定唯一归属。
4. 道路名称缺失、为空或未匹配任何交叉候选时，将 `I` 与“该 POI 命中拓宽面的本区县有效片段集合 `M`”合并去重，形成 `C = I ∪ M`。在 `C` 中按点到 path 最近距离确定唯一归属；同距执行第 5.3 节。
5. 若 `C` 为空，继续执行第 5 节普通点面归属流程，最终按本区县最近 path 兜底或保留数据异常未关联。

**交叉点规则优先于普通点面覆盖规则。** 名称匹配仅在参与交叉的道路中进行，匹配成功优先于空间最近；未匹配时必须补入 POI 命中面的其他道路，避免遗漏邻近道路。交叉参与片段进入候选不要求 POI 命中其拓宽面；补入的非交叉参与片段必须命中拓宽面，不扩大为本区县所有道路比较。

一个 POI 命中多个圆域时，一次合并全部交叉候选后执行上述顺序，不分别归属或计数。候选片段按稳定片段标识去重，道路单元按单元标识去重。圆域不作为商家计数单元。

### 4.3 P0 的交叉点处理边界

| 情况 | P0 规则 |
| --- | --- |
| 不同道路相交、端点相接 | 按交点建立圆域并计算归属 |
| 同一原道路的连续片段接点 | 不因记录分段生成额外交叉点 |
| 环路自身闭合的首尾点 | 不因闭合点生成额外交叉点 |
| 两条 path 一段重合 | 不沿重合线生成连续交叉点圆域；该范围按多面重叠规则处理 |
| 立交等平面交叉 | P0 统一按二维 path 交点计算统计归属，不引入通行、出入口或三维连通判定 |

本方案中的交叉点圆域用于空间归属，不承担真实交通连通性判断。

## 5 点面空间归属的完整决策

### 5.1 规则顺序

每个 POI 先确定所属区县，然后严格按下表从上到下执行，命中一条规则即结束本次归属，不再被后续规则覆盖。

| 优先级 | 判断条件 | 候选道路范围 | 唯一归属方法 | 关联方式 |
| --- | --- | --- | --- | --- |
| 1a | 位于交叉点圆域内，且 POI 道路名称匹配到有效交叉候选 | 本区县参与交叉且名称匹配的片段 | 匹配一个单元直接归属；多个单元在匹配片段中取最近；均记录最近片段 | 交叉点名称归属 |
| 1b | 位于交叉点圆域内，名称缺失或未匹配，且补齐后候选非空 | 本区县交叉候选 I ∪ POI 命中面的片段 M | 点到 path 最短距离取最近 | 交叉点最近归属 |
| 2 | 不适用规则 1a、1b，仅命中一个区县道路单元的拓宽面 | 该道路单元内被命中的片段 | 直接归入该单元；片段间取最近以记录沿路位置 | 单面归属 |
| 3 | 不适用规则 1a、1b，命中两个及以上道路单元的拓宽面 | 所命中面的道路片段 | 点到 path 最短距离取最近 | 多面最近归属 |
| 4 | 不适用规则 1a、1b，未命中任何道路拓宽面 | 本区县客户道路范围内全部有效片段 | 点到 path 最短距离取最近 | 最小距离兜底 |
| 5 | POI 坐标无效、行政归属无法确定，或本区县不存在有效道路 | 无可计算候选 | 保留数据异常未关联 | 数据异常未关联 |

无效坐标或无法确定行政归属的记录直接进入规则 5，不参与有效归属计算。

同一道路单元的多个拓宽片段同时覆盖 POI 时，按一个道路单元处理，不能误判为多条道路。同一道路单元参与多个交叉点时也只计一次。

### 5.2 点面命中的判定

POI 位于拓宽面的内部或边界上均视为命中；在理想距离定义下，等价于 `点到对应 path 的最短距离 ≤ 该片段的 b`。

普通区域只在命中的道路之间比较，不把未命中面的道路加入比较。单面归属不必等同于本区县全局最近道路，这是“先按等级形成关联范围，再按候选确定归属”的明确业务口径。

平行道路、主辅路、相邻道路弯道等产生的重叠范围，统一采用多面最近归属，不另建评分模型。

### 5.3 距离相等时的固定规则

交叉圆域的名称优先规则先执行；需要通过距离选择时，统一采用以下排序：

1. 点到 path 距离升序，比较精度统一为 0.01 米。
2. 距离相同时，按区县道路单元标识固定升序。
3. 同一单元内仍有多个片段相同时，按片段标识固定升序。

距离比较前不按道路等级排序，也不使用地址信息打破同距。原道路和片段标识在同一数据版本中保持稳定，保证重复计算结果一致。

### 5.4 最小距离兜底

未命中任何关联面时，直接在本区县全部有效道路片段中选择最近 path，不额外设置最大兜底距离，不因超出拓宽范围而丢弃该商家。

兜底结果与其他归属结果采用相同统计效力，直接进入道路商家数量、密度、行业及沿路分布。仅保留关联方式和计算距离用于说明结果，不增加检查或确认流程。

### 5.5 业务规则示例

| 场景 | 已知空间关系 | 归属结果 |
| --- | --- | --- |
| 普通单面命中 | 不在交叉点圆域，POI 只命中道路 A 的面 | 道路 A |
| 普通多面重叠 | 不在交叉点圆域，命中 A、B；到 path 的距离分别为 12 米、8 米 | 道路 B |
| 交叉点名称匹配 | 位于 A、B 的交叉圆域，POI 道路名称仅匹配 A；到 A、B 的距离分别为 15 米、5 米 | 道路 A，标记交叉点名称归属 |
| 交叉点同名多匹配 | 圆域内道路名称匹配两个不同道路单元，到其 path 分别为 15 米、5 米 | 在名称匹配集合中选择 5 米的道路 |
| 交叉点名称未匹配 | 交叉候选为 A、B，POI 名称缺失或未匹配；POI 同时命中非参与道路 C 的面，到 A、B、C 分别为 15 米、10 米、2 米 | 补齐候选后归 C，标记交叉点最近归属 |
| 共享边界道路 | 同一来源道路有 300 米 path 沿区县 01、02 共同边界延伸 | 该 300 米片段仅归区县 01，关联候选和道路长度均不复制到 02 |
| 没有命中面 | 到本区县最近道路 C 的 path 为 75 米 | 道路 C，标记最小距离兜底 |
| 距离相等 | 候选 A、B 的比较距离相同 | 选择道路单元标识排序在前者 |
| 无可用道路 | 商家所在区县没有有效 path | 数据异常未关联 |

| POI 相对坐标，单位米 | 到 A 的距离 | 到 B 的距离 | 圆域判定 | 归属 |
| --- | --- | --- | --- | --- |
| (25, 35) | 35 米 | 25 米 | 到交点约 43.01 米，圆域外 | 只命中 A 的面，归 A |
| (25, 30) | 30 米 | 25 米 | 到交点约 39.05 米，圆域内 | 在参与道路中 B 最近，归 B，即使超出 B 的 20 米拓宽范围 |

## 6 归属结果与沿路定位

每个商家形成一条最终归属结果，最小内容如下。

| 结果内容 | 业务含义 |
| --- | --- |
| 商家标识、实际 POI 位置 | 对应门店与实际经营位置 |
| 所属省、市、区县 | 支撑行政汇总 |
| 原道路身份、区县道路单元、命中片段 | 对应来源、统计对象及具体空间计算对象 |
| 道路等级 | 取所关联片段的等级，支持跨等级道路的局部筛选 |
| 关联方式 | 交叉点名称、交叉点最近、单面、多面最近、最小距离兜底或数据异常未关联 |
| 名称匹配依据 | 仅交叉点名称归属保留使用的 POI 道路名称与匹配道路名称，便于说明归属原因 |
| 点到 path 距离、path 上的最近位置 | 说明关联距离并支持沿路分布统计 |
| 商家行业 | 支撑一二级行业分析 |

将 POI 投影到最终归属片段 path 的最近位置，用该位置统计沿路分布；展示或输出商家位置时仍使用实际 POI 点。最近位置不被解释为商家入口。

P0 沿连续 path 按 100 米划分分析路段，末段使用实际剩余长度；跨区、等级变化或不连续片段处分别起算，不跨空隙连接。闭合环路按首尾相接处理，不把人为起点认作商业空白。

每段输出商家数量与密度，用于观察集中、稀疏和零商家段，不新增集聚模型或评分。分析路段不改变商家所属的区县道路单元，也不新增行政层级。

## 7 六个功能模块如何使用归属结果

| 功能模块 | P0 业务方案 |
| --- | --- |
| 行政层级分析 | 由区县道路归属结果向市、省汇总，支持下钻与上聚合，持续保留行业和道路等级条件 |
| 道路分布分析 | 对区县道路单元按商家数量、每公里商家数及行业结构比较和排序 |
| 单条道路分析 | 输出该单元 path、关联商家实际位置与明细、分析路段分布 |
| 分类维度 | 道路等级按关联片段筛选，商家行业按 POI 属性筛选，标签仅预留 |
| 关联与统计规则 | 执行本文五类有效归属方式与数据异常未关联处理，保证一店唯一归属 |
| 特殊场景规则 | 交叉点名称匹配优先，未匹配在补齐候选中取最近 path；多面重叠按候选最近；环路按实际连续关系；共享行政边界片段唯一归属并计量 |

## 8 指标与汇总口径

| 指标 | P0 计算规则 |
| --- | --- |
| 商家数量 | 对符合条件的有效归属门店计数；包含最小距离兜底，不重复累计点面候选或交叉点候选 |
| 道路商家密度 | 对应主归属商家数 ÷ 对应 path 长度，单位家／公里；道路长度不是拓宽面面积或面周长 |
| 行业结构 | 对最终归属商家按统一主行业统计数量及占比，未知行业单列 |
| 沿路分布 | 按 path 最近位置落入分析路段，统计各段商家数量及实际长度对应的密度 |

道路长度按第 3.3 节唯一归属的片段累计，同一来源的共享行政边界片段只计一次。区县道路长度包含零商家道路，不因行业筛选而缩短；道路等级筛选则同步选择该等级片段的商家与长度。上层密度使用汇总后的已关联商家数除以对应汇总 path 长度，不平均下层密度；无有效长度时密度不适用。

未按道路等级筛选时，同条件下：

`区域商家总量 = 有效归属商家合计 + 数据异常未关联商家数`

`区县各道路单元商家数之和 = 本区县有效归属商家合计`

市汇总下辖区县，省汇总下辖市。区域商家总量独立保留，不能把包含未关联记录的总量直接作为道路密度分子。道路详情的商家数量与相应明细、分析路段计数保持一致。

## 9 P0 完成范围

1. 客户道路 path 能按区县、道路等级形成可识别的计算片段与拓宽面。
2. 交叉点圆域由 path 交点及参与道路最大单侧拓宽距离确定；圆域内先匹配 POI 已有道路名称，未匹配则在交叉候选与命中面片段的并集中取最近。
3. 普通区域单面、多面、无面三类情况均有确定结果；有效候选下每店只归属一个区县道路单元。
4. 名称缺失、名称同名多匹配、距离同值、多个交叉点圆域重叠均按固定规则处理；同一来源的共享行政边界片段唯一归属、只累计一次长度。
5. 归属结果支撑原六个模块和四项指标，各行政层级、道路及商家明细能够对账。
6. 名称匹配仅使用交叉圆域内 POI 已有道路名称，不新增 address 文本提取、模糊匹配、通行关系推断、入口识别、复杂集聚模型或兜底检查流程。

本轮需审核的参数收敛为第 3.2 节单侧拓宽距离与第 6 节 100 米分析路段长度；交叉点半径由道路拓宽距离自动得到，不另设参数。
